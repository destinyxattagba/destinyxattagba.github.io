PROJECTS

Spotify Recommender Using Spotipy

This project is a small python program that takes a user-entered song and suggests similar tracks by the same artist. It uses the Spotify Web API and Spotipy library to authenticate, search for a track, and generate recommendations. My goal was to learn API usage, authentication, and practice data parsing in Python. Check it out here

In progress: Spotify Recommender Prototype Using React

This project will be a a mini web app prototype built with React and Vite that demonstrates how a simple command-line Spotify recommendation tool can be converted into an interactive web interface. Users can input a song or favorite artist, and the app dynamically generates a list of recommended songs based on predefined logic. Check it out here.

This project is an animated music video / lyric video to Plead the .45th by Smino and Saba, for the soundtrack of the movie Judas and the Black Messiah. Oscillation FM - Weekly Radio Show

This project / side hobby formed after I got involved with my school's radio station, WVUM. From there, Oscillation was born. Oscillation is a celebration of historically marginalized artists who've contributed insurmountable influence to modern day music, primarily through soul, r&b, and hip-hop. These genres and their respective subgenres are underlying themes in all modern popular music, so I use oscillation as a way to pay homage to these genres and play lesser known artists. Want to listen? Check out my show on every other Monday from 7-8 listen here!!

Black Creatives Collective - Executive Board

Since Fall 2022, I've been a member of Black Creatives Collective, an organization dedicated to supporting the black creative community at University of Miami at fostering collaboration. I now serve on the executive board as Event Coordinator.

Record Player Replica & Audio Movie

In my Physical Computing class, I had the creative freedom to execute an Idea that interested me for our final project. I decided to create a replica of a record player that detected the color of "vinyls" (replicas) and played specific mp3 files, telling a story. I told a short story of black hair and the black experience using pop culture clips, interviews, and news recordings.
